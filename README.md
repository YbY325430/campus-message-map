# 校原行 · 校园 2D 地图留言平台

> 第九届传智杯 AI 创新应用挑战赛 · Vibe Coding 全栈速成赛道参赛作品
> 一款基于校园 2D 地图的留言与组队平台：在地图上发布通知、留言、警示标记，并可发起组队、申请加入、添加好友。

---

## 一、项目简介

校原行把校园生活搬到一张可交互的 2D 地图上。学生、老师、校务官方账号登录后，可以在地图对应位置：

- **留言板块**：发布通知、学习、娱乐、生活类留言，支持道路警示线、警示标记、评论互动；
- **组队板块**：发起课程 / 竞赛 / 自习 / 运动组队，设置人数上限与是否需要审批，申请加入、同意或拒绝；
- **好友系统**：搜索用户、发送 / 接受 / 撤回好友申请、删除好友，并可在留言点、组队点面板内直接对作者、成员、申请人、留言者加好友；
- **角色权限**：学生、老师、官方三类身份，不同角色拥有不同的发布与管理权限。

整个项目**零构建、零前端框架**，后端 Node.js + Express，前端原生 HTML/CSS/JS，数据存储使用 Node 内置的 SQLite（`node:sqlite`），无需安装任何数据库服务。

## 二、技术栈与运行环境

| 项 | 说明 |
| --- | --- |
| 运行时 | Node.js **22.5 及以上**（使用内置实验模块 `node:sqlite`，开发环境为 v22.23.2） |
| 后端 | Node.js + Express 4 |
| 前端 | 原生 HTML / CSS / JavaScript（无框架、无打包步骤） |
| 数据库 | Node 内置 SQLite（`node:sqlite` 的 `DatabaseSync`），数据落为单个文件 |
| 生产依赖 | 仅 `express` 一个 |

> 注意：`node:sqlite` 需要 Node 22.5+。如启动时报 `Cannot find module 'node:sqlite'`，说明 Node 版本过低，请升级到 22.5 或更高版本。

## 三、10 分钟极速复现指南

### 方式 A：标准方式（推荐评审使用）

```bash
# 1. 进入项目目录
cd 01-源代码

# 2. 安装依赖（仅 express）
npm install

# 3. 初始化数据库并写入演示数据（幂等，可重复执行）
npm run init-db

# 4. 启动服务
npm start
```

看到控制台输出 `服务运行于 http://localhost:3000` 后，浏览器打开：

```
http://localhost:3000
```

### 方式 B：Windows 便携版（免安装 Node）

随参赛材料另有便携版分发包（含 `runtime/` 目录与 `启动平台.bat`）。在 Windows 上直接**双击 `启动平台.bat`** 即可，脚本会用便携 Node 自动启动并打开浏览器，无需 `npm install`。

## 五、环境变量模板

项目通过环境变量读取配置，均有默认值，**不设置也能直接运行**。

| 变量名 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 服务监听端口 |
| `CAMPUS_DB` | `server/map.db` | SQLite 数据库文件路径，可用于测试隔离或自定义部署位置 |

### 环境变量设置示例

Windows（PowerShell）：

```powershell
$env:PORT="3000"
$env:CAMPUS_DB="C:\data\campus.db"
npm start
```

macOS / Linux：

```bash
PORT=3000 CAMPUS_DB=/data/campus.db npm start
```

> 项目未使用 `dotenv`，环境变量在启动命令中直接传入即可。

## 九、可复现性说明

- 数据库文件（`server/map.db`）不随代码分发，克隆后通过 `npm run init-db` 即可确定性重建，包含完整演示账号、留言点、组队点；
- `init-db` 为幂等脚本，重复执行不会产生重复数据；
- 数据库连接开启外键约束与 5 秒忙等待，建表逻辑内置多次 `ALTER TABLE` 兼容迁移，旧库可平滑升级；
- 所有 SQL 均使用参数化查询，前端动态文本统一转义，接口不返回密码哈希与盐值。
